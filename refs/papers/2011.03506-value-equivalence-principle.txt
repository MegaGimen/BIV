The Value Equivalence Principle
for Model-Based Reinforcement Learning

Christopher Grimm Affiliation: Computer Science & Engineering Affiliation: University of Michigan 
Email: crgrimm@umich.edu    André Barreto    Satinder Singh    David Silver Affiliation: DeepMind 
Email: {andrebarreto,baveja,davidsilver}@google.com

Abstract

Learning models of the environment from data is often viewed as an essential component to building
intelligent reinforcement learning (RL) agents. The common practice is to separate the learning of
the model from its use, by constructing a model of the environment’s dynamics that correctly
predicts the observed state transitions. In this paper we argue that the limited representational
resources of model-based RL agents are better used to build models that are directly useful for
value-based planning. As our main contribution, we introduce the principle of value equivalence:
two models are value equivalent with respect to a set of functions and policies if they yield the
same Bellman updates. We propose a formulation of the model learning problem based on the value
equivalence principle and analyze how the set of feasible solutions is impacted by the choice of
policies and functions. Specifically, we show that, as we augment the set of policies and functions
considered, the class of value equivalent models shrinks, until eventually collapsing to a single
point corresponding to a model that perfectly describes the environment. In many problems, directly
modelling state-to-state transitions may be both difficult and unnecessary. By leveraging the
value-equivalence principle one may find simpler models without compromising performance, saving
computation and memory. We illustrate the benefits of value-equivalent model learning with
experiments comparing it against more traditional counterparts like maximum likelihood estimation.
More generally, we argue that the principle of value equivalence underlies a number of recent
empirical successes in RL, such as Value Iteration Networks, the Predictron, Value Prediction
Networks, TreeQN, and MuZero, and provides a first theoretical underpinning of those results.

1 Introduction

Reinforcement learning (RL) provides a conceptual framework to tackle a fundamental challenge in
artificial intelligence: how to design agents that learn while interacting with the environment [36
]. It has been argued that truly general agents should be able to learn a model of the environment
that allows for fast re-planning and counterfactual reasoning [32]. Although this is not a
particularly contentious statement, the question of how to learn such a model is far from being
resolved. The common practice in model-based RL is to conceptually separate the learning of the
model from its use. In this paper we argue that the limited representational capacity of
model-based RL agents is better allocated if the future use of the model (e.g., value-based
planning) is also taken into account during its construction [22, 15, 13].

Our primary contribution is to formalize and analyze a clear principle that underlies this new
approach to model-based RL. Specifically, we show that, when the model is to be used for
value-based planning, requirements on the model can be naturally captured by an equivalence
relation induced by a set of policies and functions. This leads to the principle of value
equivalence: two models are value equivalent with respect to a set of functions and a set of
policies if they yield the same updates under corresponding Bellman operators. The policies and
functions then become the mechanism through which one incorporates information about the intended
use of the model during its construction. We propose a formulation of the model learning problem
based on the value equivalence principle and analyze how the set of feasible solutions is impacted
by the choice of policies and functions. Specifically, we show that, as we augment the set of
policies and functions considered, the class of value equivalent models shrinks, until eventually
collapsing to a single point corresponding to a model that perfectly describes the environment.

We also discuss cases in which one can meaningfully restrict the class of policies and functions
used to tailor the model. One common case is when the construction of an optimal policy through
value-based planning only requires that a model predicts a subset of value functions. We show that
in this case the resulting value equivalent models can perform well under much more restrictive
conditions than their traditional counterparts. Another common case is when the agent has limited
representational capacity. We show that in this scenario it suffices for a model to be value
equivalent with respect to appropriately-defined bases of the spaces of representable policies and
functions. This allows models to be found with less memory or computation than conventional
model-based approaches that aim at predicting all state transitions, such as maximum likelihood
estimation. We illustrate the benefits of value-equivalent model learning in experiments that
compare it against more conventional counterparts. More generally, we argue that the principle of
value equivalence underlies a number of recent empirical successes in RL and provides a first
theoretical underpinning of those results [40, 34, 26, 16, 33].

2 Background

As usual, we will model the agent’s interaction with the environment using a Markov Decision
Process (MDP) ℳ≡⟨𝒮,𝒜,r,p,γ⟩\mathcal{M}\equiv\langle\mathcal{S},\mathcal{A},r,p,\gamma\rangle where

in state ss, p⁡(s′|s,a)p(s^{\prime}|s,a) is the transition kernel and γ∈[0,1)\gamma\in[0,1) is a
discount factor [30]. For convenience we also define r(s,a)=ES′∼p(⋅|s,a)[r(s,a,S′)]r(s,a)=\mathbb
{E}_{S^{\prime}\sim p(\cdot|s,a)}[r(s,a,S^{\prime})].

{P}(\mathcal{A}) is the space of probability distributions over 𝒜\mathcal{A}. We define Π≡{π|π:𝒮↦𝒫
(𝒜)}\mathbbl{\Pi}\equiv\{\pi\,|\,\pi:\mathcal{S}\mapsto\mathcal{P}(\mathcal{A})\} as the set of all
possible policies. The agent’s goal is to find a policy π∈Π\pi\in\mathbbl{\Pi} that maximizes the
value of every state, defined as

Many methods are available to carry out the search for a good policy [36, 39]. Typically, a crucial

RL, the focus of this paper, the agent learns approximations r~≈r\tilde{r}\approx r and p~≈p\tilde
{p}\approx p and use them to compute (2) with pp and rr replaced by p~\tilde{p} and r~\tilde{r} [36

3 Value equivalence

Given a state space 𝒮\mathcal{S} and an action space 𝒜\mathcal{A}, we call the tuple m≡(r,p)m\equiv
(r,p) a model. Note that a model plus a discount factor γ\gamma induces a Bellman operator (2) for
every policy π∈Π\pi\in\mathbbl{\Pi}. In this paper we are interested in computing an approximate
model m~=(r~,p~)\tilde{m}=(\tilde{r},\tilde{p}) such that the induced operators 𝒯~π\tilde{\mathcal
{T}}_{\pi}, defined analogously to (2), are good approximations of the true 𝒯π\mathcal{T}_{\pi}.
Our main argument is that models should only be distinguished with respect to the policies and
functions they will actually be applied to. This leads to the following definition:

Definition 0 (Value equivalence).

Let Π⊆Π\Pi\subseteq\mathbbl{\Pi} be a set of policies and let 𝒱⊆V\mathcal{V}\subseteq\mathbbl{{V}}
be a set of functions. We say that models mm and m~\tilde{m} are value equivalent with respect to Π
\Pi and 𝒱\mathcal{V} if and only if

 𝒯π​v=𝒯~π​v​ for all ​π∈Π​ and all ​v∈𝒱,\mathcal{T}_{\pi}v=\tilde{\mathcal{T}}_{\pi}v\text{ for
 all }\pi\in\Pi\text{ and all }v\in\mathcal{V},

where 𝒯π\mathcal{T}_{\pi} and 𝒯~π\tilde{\mathcal{T}}_{\pi} are the Bellman operators induced by mm
and m~\tilde{m}, respectively.

Two models are value equivalent with respect to Π\Pi and 𝒱\mathcal{V} if the effect of the Bellman
operator induced by any policy π∈Π\pi\in\Pi on any function v∈𝒱v\in\mathcal{V} is the same for both
models. Thus, if we are only interested in Π\Pi and 𝒱\mathcal{V}, value-equivalent models are
functionally identical. This can be seen as an equivalence relation that partitions the space of
models conditioned on Π\Pi and 𝒱\mathcal{V}:

Definition 0 (Space of value-equivalent models).

Let Π\Pi and 𝒱\mathcal{V} be defined as above and let ℳ\mathcal{M} be a space of models. Given a
model mm, the space of value-equivalent models ℳm​(Π,𝒱)⊆ℳ\mathcal{M}_{m}(\Pi,\mathcal{V})\subseteq\
mathcal{M} is the set of all models m~∈ℳ\tilde{m}\in\mathcal{M} that are value equivalent to mm
with respect to Π\Pi and 𝒱\mathcal{V}.

Let M\mathbbl{{M}} be a space of models containing at least one model m∗m^{*} which perfectly
describes the interaction of the agent with the environment. More formally, m∗m^{*} induces the
true Bellman operators 𝒯π\mathcal{T}_{\pi} defined in (2). Given a space of models ℳ⊆M\mathcal{M}\
subseteq\mathbbl{{M}}, often one is interested in models m∈ℳm\in\mathcal{M} that are value
equivalent to m∗m^{*}. We will thus simplify the notation by defining ℳ⁡(Π,𝒱)≡ℳm∗​(Π,𝒱)\mathcal{M}
(\Pi,\mathcal{V})\equiv\mathcal{M}_{m^{*}}(\Pi,\mathcal{V}).

3.1 The topology of the space of value-equivalent models

The space ℳ⁡(Π,𝒱)\mathcal{M}(\Pi,\mathcal{V}) contains all the models in ℳ\mathcal{M} that are
value equivalent to the true model m∗m^{*} with respect to Π\Pi and 𝒱\mathcal{V}. Since any two
models m,m′∈ℳ⁡(Π,𝒱)m,m^{\prime}\in\mathcal{M}(\Pi,\mathcal{V}) are equally suitable for value-based
planning using Π\Pi and 𝒱\mathcal{V}, we are free to use other criteria to choose between them. For
example, if mm is much simpler to represent or learn than m′m^{\prime}, it can be preferred without
compromises.

Clearly, the principle of value equivalence can be useful if leveraged in the appropriate way. In
order for that to happen, it is important to understand the space of value-equivalent models ℳ⁡
(Π,𝒱)\mathcal{M}(\Pi,\mathcal{V}). We now provide intuition for this space by analyzing some of its
core properties. We refer the reader to Figure 1 for an illustration of the concepts to be
discussed in this section. We start with a property that follows directly from Definitions 1 and 2:

Given ℳ′⊆ℳ\mathcal{M}^{\prime}\subseteq\mathcal{M}, we have that ℳ′​(Π,𝒱)⊆ℳ⁡(Π,𝒱)\mathcal{M}^{\

The proofs of all theoretical results are in Appendix A.1. Property 1 states that, given a set of
policies Π\Pi and a set of functions 𝒱\mathcal{V}, reducing the size of the space of models ℳ\
mathcal{M} also reduces the space of value-equivalent models ℳ⁡(Π,𝒱)\mathcal{M}(\Pi,\mathcal{V}).
One immediate consequence of this property is that, if we consider the space of all policies Π\
mathbbl{\Pi} and the space of all functions V\mathbbl{{V}}, we have one of two possibilities:
either we end up with a perfect model or we end up with no model at all. Or, more formally:

Property 2.

ℳ⁡(Π,V)\mathcal{M}(\mathbbl{\Pi},\mathbbl{{V}}) either contains m∗m^{*} or is the empty set.

Property 1 describes what happens to ℳ⁡(Π,𝒱)\mathcal{M}(\Pi,\mathcal{V}) when we vary ℳ\mathcal{M}
with fixed Π\Pi and 𝒱\mathcal{V}. It is also interesting to ask what happens when we fix the former
and vary the latter. This leads to the next property:

Property 3.

Given Π′⊆Π\Pi^{\prime}\subseteq\Pi and 𝒱′⊆𝒱\mathcal{V}^{\prime}\subseteq\mathcal{V}, we have that
ℳ⁡(Π,𝒱)⊆ℳ⁡(Π′,𝒱′)\mathcal{M}(\Pi,\mathcal{V})\subseteq\mathcal{M}(\Pi^{\prime},\mathcal{V}^{\
prime}).

According to Property 3, as we increase the size of Π\Pi or 𝒱\mathcal{V} the size of ℳ⁡(Π,𝒱)\
mathcal{M}(\Pi,\mathcal{V}) decreases. Although this makes intuitive sense, it is reassuring to
know that value equivalence is a sound principle for model selection, since by adding more policies
to Π\Pi or more values to 𝒱\mathcal{V} we can progressively restrict the set of feasible solutions.
Thus, if ℳ\mathcal{M} contains the true model, we eventually pin it down. Indeed, in this case the
true model belongs to all spaces of value equivalent models, as formalized below:

Property 4.

If m∗∈ℳm^{*}\in\mathcal{M}, then m∗∈ℳ⁡(Π,𝒱)m^{*}\in\mathcal{M}(\Pi,\mathcal{V}) for all Π\Pi and
all 𝒱\mathcal{V}.

3.2 A basis for the space of value-equivalent models

As discussed, it is possible to use the sets Π\Pi and 𝒱\mathcal{V} to control the size of ℳ⁡(Π,𝒱)\
mathcal{M}(\Pi,\mathcal{V}). But what exactly is the effect of Π\Pi and 𝒱\mathcal{V} on ℳ⁡(Π,𝒱)\

when we, say, add one function to 𝒱\mathcal{V}? In this section we address this and similar
questions.

intuitive sense if we note that by definition m≤|𝒜|m\leq|\mathcal{A}|: for an expressive enough Π\
Pi, each v∈𝒱v\in\mathcal{V} will provide information about the effect of all actions in a∈𝒜a\in\
mathcal{A}. Conversely, because span⁡(𝒱)=k≤|𝒮|\mathrm{span}(\mathcal{V})=k\leq|\mathcal{S}|, we can
only go so far in pinning down the model when m<|𝒜|m<|\mathcal{A}|—which also makes sense, since in
this case we cannot possibly know about the effect of all actions, no matter how big 𝒱\mathcal{V}
is. Note that when m=|𝒜|m=|\mathcal{A}| and k=|𝒮|k=|\mathcal{S}| the space P⁡(Π,𝒱)\mathbb{P}(\Pi,\
mathcal{V}) reduces to {𝑷∗}\{\boldsymbol{{P}}^{*}\}.

4 Model learning based on the value-equivalence principle

We now discuss how the principle of value equivalence can be incorporated into model-based RL.
Often in model-based RL one learns a model m~=(r~,p~)\tilde{m}=(\tilde{r},\tilde{p}) without taking
the space ℳ⁡(Π,𝒱)\mathcal{M}(\Pi,\mathcal{V}) into account. The usual practice is to cast the
approximations r~≈r\tilde{r}\approx r and p~≈p\tilde{p}\approx p as optimization problems over a
model-space ℳ\mathcal{M} that do not involve the sets Π\Pi and 𝒱\mathcal{V}. Given a space ℛ\

rewards as argminr~∈ℛ​ℓr​(r,r~)\mathrm{argmin}_{\tilde{r}\in\mathcal{R}}\ell_{r}(r,\tilde{r}),
where ℓr\ell_{r} is a loss function that measures the dissimilarity between rr and r~\tilde{r}. The
approximation of the transition dynamics can be formalized in an analogous way: argminp~∈𝒫​ℓp​

usually defined based on the principle of maximum likelihood estimation (MLE):

posterior inference [13]. Although we focus on MLE for simplicity, our arguments should extend to

Both (4) and (5) have desirable properties that justify their widespread adoption [24]. However, we
argue that ignoring the future use of r~\tilde{r} and p~\tilde{p} may not always be the best

4.1 Restricting the sets of policies and functions

The main argument of this paper is that, rather than learning a model that suits all policies Π\
mathbbl{\Pi} and all functions V\mathbbl{{V}}, we should instead focus on the sets of policies Π\Pi
and functions 𝒱\mathcal{V} that are necessary for planning. But how can we know these sets a priori
? We now show that it is possible to exploit structure on both the problem and the solution sides.

First, we consider structure in the problem. Suppose we had access to the true model m∗m^{*}. Then,
given an initial function vv, a value-based planning algorithm that makes use of m∗m^{*} will
generate a sequence of functions 𝒱→v≡{v1,v2,…}\vec{\mathcal{V}}_{v}\equiv\{v_{1},v_{2},...\} [10].
Clearly, if we replace m∗m^{*} with any model in ℳ⁡(Π,𝒱→v)\mathcal{M}(\mathbbl{\Pi},\vec{\mathcal
{V}}_{v}), the behavior of the algorithm starting from vv remains unaltered. This allows us to
state the following:

Proposition 0.

Suppose v∈𝒱′⟹𝒯π​v∈𝒱′v\in\mathcal{V}^{\prime}\implies\mathcal{T}_{\pi}v\in\mathcal{V}^{\prime} for
all π∈Π\pi\in\mathbbl{\Pi}. Let p​-​span​(Π)⊇Πp\text{-}\mathrm{span}(\Pi)\supseteq\mathbbl{\Pi} and
span⁡(𝒱)=𝒱′\mathrm{span}(\mathcal{V})=\mathcal{V}^{\prime}. Then, starting from any v′∈𝒱′v^{\prime}
\in\mathcal{V}^{\prime}, any m~∈ℳ⁡(Π,𝒱)\tilde{m}\in\mathcal{M}(\Pi,\mathcal{V}) yields the same
solution as m∗m^{*}.

Because 𝒯π\mathcal{T}_{\pi} are contraction mappings, it is always possible to define a 𝒱′⊂V\
mathcal{V}^{\prime}\subset\mathbbl{{V}} such that the condition of Proposition 7 holds: we only
need to make 𝒱′\mathcal{V}^{\prime} sufficiently large to encompass vv and the operators’ fixed
points. But in some cases there exist more structured 𝒱′\mathcal{V}^{\prime}: in Appendix A.1 we
give an example of a finite state-space MDP in which a sequence 𝒗1,𝒗2=𝒯π​𝒗1,𝒗3=𝒯π′​𝒗2,…\boldsymbol
{{v}}_{1},\boldsymbol{{v}}_{2}=\mathcal{T}_{\pi}\boldsymbol{{v}}_{1},\boldsymbol{{v}}_{3}=\mathcal
{T}_{\pi^{\prime}}\boldsymbol{{v}}_{2},... that reaches a specific kk-dimensional subspace of R|S|\
mathbb{R}^{|S|} stays there forever. The value equivalence principle provides a mechanism to
exploit this type of structure, while conventional model-learning approaches, like MLE, are
oblivious to this fact. Although in general we do not have access to 𝒱′\mathcal{V}^{\prime}, in
some cases this set will be revealed through the very process of enforcing value equivalence. For
example, if m~\tilde{m} is being learned online based on a sequence v1,v2=𝒯π​v1,v3=𝒯π′​v2,…v_{1},v_
{2}=\mathcal{T}_{\pi}v_{1},v_{3}=\mathcal{T}_{\pi^{\prime}}v_{2},..., as long as the sequence
reaches a vi∈𝒱′v_{i}\in\mathcal{V}^{\prime} we should expect m~\tilde{m} to eventually specialize
to 𝒱′\mathcal{V}^{\prime} [13, 33].

Another possibility is to exploit geometric properties of the value functions 𝒱→v\vec{\mathcal{V}}_
{v}. It is known that the set of all value functions of a given MDP forms a polytope 𝒱¨⊂V\ddot{\
mathcal{V}}\subset\mathbbl{{V}} [11]. Even though the sequence 𝒱→v\vec{\mathcal{V}}_{v} an
algorithm generates may not be strictly inside the polytope 𝒱¨\ddot{\mathcal{V}}, this set can
still serve as a reference in the definition of 𝒱\mathcal{V}. For example, based on Proposition 3,
we may want to define a 𝒱\mathcal{V} that spans as much of the polytope 𝒱¨\ddot{\mathcal{V}} as
possible [5]. This suggests that the functions in 𝒱\mathcal{V} should be actual value functions
vπv_{\pi} associated with policies π∈Π\pi\in\mathbbl{\Pi}. In Section 5 we show experiments that
explore this idea.

We now consider structure in the solution. Most large-scale applications of model-based RL use
function approximation. Suppose the agent can only represent policies π∈Π~\pi\in\tilde{\Pi} and
value functions v∈𝒱~v\in\tilde{\mathcal{V}}. Then, a value equivalent model m~∈ℳ⁡(Π~,𝒱~)\tilde{m}\
in\mathcal{M}(\tilde{\Pi},\tilde{\mathcal{V}}) is as good as any model. To build intuition, suppose
the agent uses state aggregation to approximate the value function. In this case two models with
the same transition probabilities between clusters of states are indistinguishable from the agent’s
point of view. It thus makes sense to build 𝒱\mathcal{V} using piecewise-constant functions that
belong to the space of function representable by the agent, v∈𝒱~v\in\tilde{\mathcal{V}}. The
following remark generalises this intuition:

Remark 0.

Suppose the agent represents the value function using a linear function approximation: 𝒱~={v~|v~​
(s)=∑i=1dϕi​(s)​wi}\tilde{\mathcal{V}}=\{\tilde{v}\,|\,\tilde{v}(s)=\sum_{i=1}^{d}\phi_{i}(s)w_{i}
\}, where ϕi:𝒮↦R\phi_{i}:\mathcal{S}\mapsto\mathbb{R} are fixed features and 𝐰∈Rd\boldsymbol{{w}}\
in\mathbb{R}^{d} are learnable parameters. In addition, suppose the agent can only represent
policies π∈Π~\pi\in\tilde{\Pi}. Then, Proposition 3 implies that if we use the features themselves
as the functions adopted with value equivalence, 𝒱={ϕi}i=1d\mathcal{V}=\{\phi_{i}\}_{i=1}^{d}, we
have that ℳ⁡(Π~,{ϕi}i=1d)=ℳ⁡(Π~,𝒱~)\mathcal{M}(\tilde{\Pi},\{\phi_{i}\}_{i=1}^{d})=\mathcal{M}(\
tilde{\Pi},\tilde{\mathcal{V}}). In other words, models that are value equivalent with respect to
the features are indiscernible to the agent.

According to the remark above, when using linear function approximation, a model that is value
equivalent with respect to the approximator’s features will perform no worse than any other model.
This prescribes a concrete way to leverage the value equivalence principle in practice, since the
set of functions 𝒱\mathcal{V} is automatically defined by the choice of function approximator. Note
that, although the remark is specific to linear value function approximation, it applies equally to
linear and non-linear models (this is in contrast with previous work showing the equivalence
between model-free RL using linear function approximation and model-based RL with a linear model
for expected features [27, 38]). The principle of finding a basis for 𝒱~\tilde{\mathcal{V}} also
extends to non-linear value function approximation, though in this case it is less clear how to
define a set 𝒱\mathcal{V} that spans 𝒱~\tilde{\mathcal{V}}. One strategy is to sample the functions
to be included in 𝒱\mathcal{V} from the set 𝒱~\tilde{\mathcal{V}} of (non-linear) functions the
agent can represent. Despite its simplicity, this strategy can lead to good performance in
practice, as we show next.

5 Experiments

We now present experiments illustrating the usefulness of the value equivalence principle in
practice. Specifically, we compare models computed based on value equivalence (VE) with models
resulting from maximum likelihood estimation (MLE). All our experiments followed the same protocol:
(i)(i) we collected sample transitions from the environment using a policy that picks actions
uniformly at random, (i​i)(ii) we used this data to learn an approximation r~\tilde{r} using (4) as
well as approximations p~\tilde{p} using either MLE (5) or VE (7), (i​i​i)(iii) we learned a policy
π~\tilde{\pi} based on m~=(r~,p~)\tilde{m}=(\tilde{r},\tilde{p}), and (i​v)(iv) we evaluated π~\
tilde{\pi} on the actual environment. The specific way each step was carried out varied according
to the characteristics of the environment and function approximation used; see App. A.2 for
details.

One of the central arguments of this paper is that the value equivalence principle can yield a
better allocation of the limited resources of model-based agents. In order to verify this claim, we
varied the representational capacity of the agent’s models m~\tilde{m} and assessed how well MLE
and VE performed under different constraints. As discussed, VE requires the definition of two sets:
Π\Pi and 𝒱\mathcal{V}. It is usually easy to define a set of policies Π\Pi such that p​-​span​(Π)
⊇Πp\text{-}\mathrm{span}(\Pi)\supseteq\mathbbl{\Pi}; since all the environments used in our
experiments have a finite action space 𝒜\mathcal{A}, we accomplished that by defining Π={πa}a∈𝒜\Pi=
\{\pi^{a}\}_{a\in\mathcal{A}} where πa​(a|s)=1\pi^{a}(a|s)=1 for all s∈𝒮s\in\mathcal{S}. We will
thus restrict our attention to the impact of the set of functions 𝒱\mathcal{V}.

As discussed, one possible strategy to define 𝒱\mathcal{V} is to use actual value functions in an
attempt to span as much as possible of the value polytope 𝒱¨\ddot{\mathcal{V}} [5]. Figure 3 shows
results of VE when using this strategy. Specifically, we compare VE’s performance with MLE’s on two
well known domains: “four rooms” [37] and “catch” [25]. For each domain, we show two types of
results: we either fix the capacity of the model p~\tilde{p} and vary the size of 𝒱\mathcal{V} or
vice-versa (in the Appendix we show results with all possible combinations of model capacities and
sizes of 𝒱\mathcal{V}). Note how the models produced by VE outperform MLE’s counterparts across all
scenarios, and especially so under stricter restrictions on the model. This corroborates our
hypothesis that VE yields models that are tailored to future use.

guarantee, we see a considerable gap in performance between VE and MLE, indicating that VE models
still offer a strong benefit. Our goal here was to provide insight into the value equivalence
principle; in the next section we point to prior work to demonstrate the utility of value

6 The value-equivalence principle in practice

Recently, there have been several successful empirical works that can potentially be understood as
applications of the value-equivalence principle, like Silver et al.’s [34] Predictron, Oh et al.’s 
[26] Value Prediction Networks, Farquhar et al.’s [16] TreeQN, and Schrittwieser et al.’s [33]
MuZero. Specifically, the model-learning aspect of these prior methods can be understood, with some
abuse of notation, as a value equivalence principle of the form 𝒯​v=𝒯~​v\mathcal{T}v=\tilde{\
mathcal{T}}v, where 𝒯\mathcal{T} is a Bellman operator applied with the true model m∗m^{*} and 𝒯~\

There are many possible forms for the operators 𝒯\mathcal{T} and 𝒯~\tilde{\mathcal{T}}. First,
value equivalence can be applied to an uncontrolled Markov reward process; the resulting operator
𝒯π\mathcal{T}_{\pi} is analogous to having a single policy in Π\Pi. Second, it can be applied over
nn steps, using a Bellman operator 𝒯πn\mathcal{T}_{\pi}^{n} that rolls the model forward nn steps:

{t+1}+...+\gamma^{n-1}R_{t+n}+\gamma^{n}v_{\pi}(S_{t+n})|S_{t}=s], or a λ\lambda-weighted average
𝒯πλ\mathcal{T}_{\pi}^{\lambda} [6]. Third, a special case of the nn-step operator 𝒯a1​…​an\mathcal
{T}_{a_{1}...a_{n}} can be applied to an open-loop action sequence {a1,…,an}\{a_{1},...,a_{n}\}.
Fourth, it can be applied to the Bellman optimality operator, 𝒯Gv\mathcal{T}_{G_{v}}, where GvG_{v}
is the “greedy” policy induced by vv defined as Gv(a|s)=𝟙{a=argmaxa′E[R+γv(S’)|s,a′]}G_{v}(a|s)=\
mathbbm{1}\{a=\mathrm{argmax}_{a^{\prime}}\mathbb{E}[R+\gamma v(S\textquoteright)|s,a^{\prime}]\}.
This idea can also be extended to an nn-step greedy search operator, 𝒯Gvn[v](s)=maxa1,…,anE
[Rt+1+…+γn−1Rt+n+γnv(St+n)|St=s,At=a1,…,At+n=an]\mathcal{T}_{G_{v}^{n}}[v](s)=\max_{a_{1},...,a_

=a_{n}]. Finally, instead of applying value equivalence over a fixed set of value functions 𝒱\
mathcal{V}, we can have a set 𝒱t\mathcal{V}_{t} that varies over time—for example, 𝒱t\mathcal{V}_
{t} can be a singleton with an estimate of the value function of the current greedy policy.

The two operators 𝒯\mathcal{T} and 𝒯~\tilde{\mathcal{T}} can also differ. For example, on the
environment side we can use the optimal value function, which can be interpreted as 𝒯∞​v=v∗\mathcal

{\lambda} [34] or 𝒯~Gvtn\tilde{\mathcal{T}}_{G_{v_{t}}}^{n} [40]. We can also use approximate

mathcal{T}^{n}\tilde{\mathcal{T}}^{k}v [16], or even to approximate policies, 𝒯~n​va≈𝒯n​va′\tilde{\

7 Related work

Farahmand et al.’s [14, 15] value-aware model learning (VAML) is based on a premise similar to
ours. They study a robust variant of (6) that considers the worst-case choice of v∈𝒱v\in\mathcal{V}
and provide the gradient when the value-function approximation v~\tilde{v} is linear and the model
p~\tilde{p} belongs to the exponential family. Later, Farahmand [13] also considered the case where
the model is learned iteratively. Both versions of VAML come with finite sample-error upper bound
guarantees [14, 15, 13]. More recently, Asadi et al. [2] showed that minimizing the VAML objective
is equivalent to minimizing the Wasserstein metric. Abachi et al. [1] applied the VAML principle to
policy gradient methods. The theory of VAML is complementary to ours: we characterise the space of
value-equivalent models, while VAML focuses on the solution and analysis of the induced
optimization problem.

Joseph et al. [22] note that minimizing prediction error is not the same as maximizing the
performance of the resulting policy, and propose an algorithm that optimizes the parameters of the
model rather than the policy’s. Ayoub et al. [3] proposes an algorithm that keeps a set of models
that are consistent with the most recent value function estimate. They derive regret bounds for the
algorithm which suggest that value-targeted regression estimation is both sufficient and efficient
for model-based RL.

More broadly, other notions of equivalence between MDPs have been proposed in the literature [12,
28, 20, 31, 17, 23, 41, 29, 8, 42]. Any notion of equivalence over states can be recast as a form
of state aggregation; in this case the functions mapping states to clusters can (and probably
should) be used to enforce value equivalence (Remark 8). But the principle of value equivalence is
more general: it can be applied with function approximations other than state aggregation and can
be used to exploit structure in the problem even when there is no clear notion of state abstraction
(Appendix A.1.2).

In this paper we have assumed that the agent has access to a well-defined notion of state s∈𝒮s\in\
mathcal{S}. More generally, the agent only receives observations from the environment and must
construct its own state function—that is, a mapping from histories of observations to features
representing states. This is an instantiation of the problem known as representation learning [43,
21, 9, 18, 45, 44, 19, 7]. An intriguing question which arises in this context is whether a model
learned through value equivalence induces a space of “compatible” state representations, which
would suggest that the loss (6) could also be used for representation learning. This may be an
interesting direction for future investigations.

8 Conclusion

We introduced the principle of value equivalence: two models are value equivalent with respect to a
set of functions and a set of policies if they yield the same updates of the former on the latter.
Value equivalence formalizes the notion that models should be tailored to their future use and
provides a mechanism to incorporate such knowledge into the model learning process. It also unifies
some important recent work in the literature, shedding light on their empirical success. Besides
helping to explain some past initiatives, we believe the concept of value equivalence may also give
rise to theoretical and algorithmic innovations that leverage the insights presented.

Broader impact

The bulk of the research presented in this paper consists of foundational theoretical results about
the learning of models for model-based reinforcement learning agents. While applications of these
agents can have social impacts depending upon their use, our results merely serve to illuminate
desirable properties of models and facilitate the subsequent training of agents using them. In
short, this work is largely theoretical and does not present any foreseeable societal impact,
except in the general concerns over progress in artificial intelligence.

A.2.2 Experimental pipeline

As mentioned in the main text, a common experimental pipeline is used across all of our results,
with slight variations depending upon the experiment type and environment. This pipeline is
described at a high-level below:

 1. 1.
   
    Data collection: Data is collected using a policy which selects actions uniformly at random.

 2. 2.
   
    Model training: The collected data is used to train a model.

 3. 3.
   
    Policy construction: The model is used to produce a policy.

 4. 4.
   
    Policy evaluation: The policy is evaluated to assess the quality of the model.

We now discuss steps 2, 3 and 4 in detail.

3 Policy construction

In each experiment we present, after a model is constructed, we subsequently use it to construct a
policy. The manner in which we do this varies based upon the type of the experiment and the nature
of the environment. There are three mechanisms for constructing policies from models:

 1. 1.
   
    Value iteration: For experiments with 𝒱=V\mathcal{V}=\mathbbl{{V}} (which are performed only
    with tabular models), we use the learned model m~=(r~,p~)\tilde{m}=(\tilde{r},\tilde{p}) to
    perform value iteration until convergence, yielding v~∗\tilde{v}^{*} [30]. Here v~∗\tilde{v}^
    {*} represents the optimal value function of the model m~\tilde{m}. We then produce a policy
    according to π⁡(s)=argmaxa​(r~​(s,a)+γ​∑s′p~​(s′|s,a)​v~∗​(s′))\pi(s)=\text{argmax}_{a}(\tilde
    {r}(s,a)+\gamma\sum_{s^{\prime}}\tilde{p}(s^{\prime}|s,a)\tilde{v}^{*}(s^{\prime})).

 2. 2.
   
    Approximate policy iteration with least squares temporal-difference learning (LSTD): For
    experiments on environments with finite 𝒮\mathcal{S} and 𝒱=𝒱~\mathcal{V}=\tilde{\mathcal{V}} we
    used policy iteration combined with least square policy evaluation using basis {ϕi}i=1d\{\phi_
    {i}\}_{i=1}^{d}. Specifically, each iteration of policy iteration involved the following steps:

4 Policy evaluation

There are two methods to evaluate the policies resulting from the policy construction stage
described above:

 1. 1.
   
    For policies produced using value iteration or policy iteration plus LSTD the ensuing policy, π
    \pi, is exactly evaluated on the true environment, yielding vπ​(s)v_{\pi}(s). Then the average
    value of vπ​(s)v_{\pi}(s) over all states is reported.

 2. 2.
   
    For policies produced using DQN, the average return over the last 100100 episodes of training
    is reported.

A.2.3 Classes of experiments

In addition to varying the capacity of ℳ\mathcal{M}, there are two primary classes of experiments
that were run in our paper that assess different choices of 𝒱\mathcal{V}. We distinguish between
these two classes below:

𝐬𝐩𝐚𝐧⁡(𝓥)≈𝓥¨,𝓥~=𝑽,𝚷=𝚷\boldsymbol{\mathrm{span}(\mathcal{V})\approx\ddot{\mathcal{V}},\tilde{\mathcal
{V}}=\mathbbl{{V}},\Pi=\mathbbl{\Pi}}:

In these experiments we consider that there is no limitation on the agent’s ability to represent
value functions, and focus on achieving value equivalence with respect to the polytope of value
functions 𝒱¨\ddot{\mathcal{V}} induced by the environment. We enable the agent to represent
arbitrary functions in V\mathbbl{{V}} by restricting ourselves to tabular environments and using
dynamic programming to perform exact value iteration in our Policy Construction step. We
approximate the value polytope by randomly sampling deterministic policies: {π1,…,πn}\{\pi_{1},\
ldots,\pi_{n}\} and evaluating them (again using dynamic programming) to produce {vπ1,…,vπn}\{v_{\
pi_{1}},\ldots,v_{\pi_{n}}\}. We then choose 𝒱={vπ1,…,vπn}\mathcal{V}=\{v_{\pi_{1}},\ldots,v_{\pi_
{n}}\}. In this setting we vary the number of policies generated.

Corresponding experiments: the experiments in this class vary two dimensions: (1) the rank of the
model and (2) the number of policies generated. In Figures 3(a) and 3(b) we depict plots for the
Four Rooms environment that fix the number of policies while varying the rank of the model and
plots that fix the rank of the model while varying the number of policies, respectively. Figures 3
(c) and 3(d) are analogous plots for the Catch environment.

𝐬𝐩𝐚𝐧⁡(𝓥)≈𝓥~\boldsymbol{\mathrm{span}(\mathcal{V})\approx\tilde{\mathcal{V}}}, 𝚷=𝚷\boldsymbol{\Pi=\
mathbbl{\Pi}}:

In these experiments we explore the setting described in Remark 8. We assume that the agent has
variable ability to represent value functions, 𝒱~\tilde{\mathcal{V}}, and attempt to learn a model
in ℳ⁡(𝒱~,Π)\mathcal{M}(\tilde{\mathcal{V}},\mathbbl{\Pi}). From Proposition 3 we only need to find
𝒱\mathcal{V} such that span⁡(𝒱)⊇𝒱~\mathrm{span}(\mathcal{V})\supseteq\tilde{\mathcal{V}}.
Experiments in this class can further be broken down into two settings based upon the nature of 𝒱~\
tilde{\mathcal{V}}:

 1. (a)
   
    Linear function approximation: In certain experiments our agent uses a class of linear function
    approximators to represent value functions: 𝒱~={v~:v~​(s)=∑i=1dϕi​(s)​wi}\tilde{\mathcal{V}}=\
    {\tilde{v}:\tilde{v}(s)=\sum_{i=1}^{d}\phi_{i}(s)w_{i}\} where ϕi​(s):𝒮↦R\phi_{i}(s):\mathcal
    {S}\mapsto\mathbb{R} and 𝒘∈Rd\boldsymbol{w}\in\mathbb{R}^{d}. In this setting achieving span⁡
    (𝒱)⊇𝒱~\mathrm{span}(\mathcal{V})\supseteq\tilde{\mathcal{V}} can be satisfied by choosing 𝒱=
    {ϕi}i=1d\mathcal{V}=\{\phi_{i}\}_{i=1}^{d}. For experiments using linear function
    approximation, we select our features {ϕi}i=1d\{\phi_{i}\}_{i=1}^{d} to correspond to state
    aggregations. This entails the following procedure:

     1. (a)
       
        Collect data using a policy that selects actions uniformly at random.

     2. (b)
       
        For tabular domains (e.g., Catch, Four Rooms), convert tabular state representations into
        coordinate-based representations. For Catch we convert each tabular state into the
        positions of both the paddle and the ball: (xpaddle,ypaddle,xball,yball)(x_{\text
        {paddle}},y_{\text{paddle}},x_{\text{ball}},y_{\text{ball}}). For Four Rooms we use the
        position of the agent: (xagent,yagent)(x_{\text{agent}},y_{\text{agent}}). Denote the
        function that performs this conversion as: f:𝒮↦Rnf:\mathcal{S}\mapsto\mathbb{R}^{n} where n
        =2n=2 and n=4n=4 for Four Rooms and Catch respectively.

     3. (c)
       
        Perform k-means clustering on these converted states to produce dd centers c1:dc_{1:d}.

     4. (d)
       
        Define ϕi(s)=𝟙{argminj∥f(s)−cj∥2=i}\phi_{i}(s)=\mathbbm{1}\{\text{argmin}_{j}\ \|f(s)-c_{j}
        \|_{2}=i\}, which corresponds to aggregating states according to their proximity to the
        previously calculated centers.

    Corresponding experiments: the experiments in this class vary two dimensions: (1) the rank of
    the model and (2) the number of basis functions in {ϕi}i=1d\{\phi_{i}\}_{i=1}^{d}. In Figures 4
    (a) and 4(b) we depict plots of “slices” of this two-dimensional set of results on the Catch
    domain: 4(a) depicts fixing the number of basis functions while varying model-rank and 4(b)
    depicts fixing the model-rank while varying the number of basis functions.

 2. (b)
   
    Neural network function approximation: When Neural Networks are used to approximate the agent’s
    value functions we have 𝒱~={v~:v~​(s)=gθ​(s)}\tilde{\mathcal{V}}=\{\tilde{v}:\tilde{v}(s)=g_{\
    theta}(s)\} where gθg_{\theta} represents a neural network with a particular architecture
    parameterized by θ\theta. In our experiments we choose the architecture of gθg_{\theta} to be a
    2 layer neural network with a tanh activation for its hidden layer. Unlike the linear function
    approximation setting, it is less obvious how to choose 𝒱\mathcal{V} such that span⁡(𝒱)⊇𝒱~\
    mathrm{span}(\mathcal{V})\supseteq\tilde{\mathcal{V}}. One option is to use randomly
    initialized neural networks in 𝒱~\tilde{\mathcal{V}} as our basis. To randomly initialize a
    given layer in some network gθg_{\theta}, we select weights from a truncated normal
    distribution where μ=0\mu=0 and σ=1/layer-input-size\sigma=1/\sqrt{\text{layer-input-size}} and
    initialize biases to 00.

    However, we found in practice that a large number of these randomly initialized networks were
    required to achieve reasonable performance. Instead of maintaining a large set of
    initializations in 𝒱\mathcal{V}, we allow the elements of 𝒱\mathcal{V} themselves to be
    stochastic. Every time we apply an update of gradient descent we sample a new set of randomly
    initialized neural networks to function as 𝒱\mathcal{V}. This is equivalent to minimizing E𝒱​
    [ℓΠ,𝒱,𝒟′​(m∗,m~)]\mathbb{E}_{\mathcal{V}}[\ell_{\Pi,\mathcal{V},\mathcal{D}^{\prime}}(m^{*},\
    tilde{m})] where ℓΠ,𝒱,D′\ell_{\Pi,\mathcal{V},D^{\prime}} is defined in 7. We find that having
    more random elements in 𝒱\mathcal{V} decreases the variance in the performance of VE models; |𝒱
    |=5|\mathcal{V}|=5 in our experiments.

    Corresponding experiments: the experiments in this class vary two dimensions: (1) the rank of
    the model and (2) the width of the neural networks in 𝒱~\tilde{\mathcal{V}}. In Figures 4(c)
     and 4(d) we depict plots of “slices” of this two-dimensional set of results on the Catch
    domain: 4(c) depicts fixing the network width while varying model-rank and 4(d) depicts fixing
    the model-rank while the network width varies.
