Textual Belief States for World Models: Identifiable Representation Learning Under Strict Mediation

Xiang Gao    Kaiwen Dong    Yuguang Yao    Padmaja Jonnalagedda    Kamalika Das Affiliation: Intuit
AI Research Affiliation: {xiang_gao, kamalika_das}@intuit.com

Abstract

World models in partially observed environments rely on latent representations that summarize
interaction history, but in many modern LLM-based architectures predictive performance fails to
reflect representation quality due to history bypass, rendering the latent state unidentifiable.
Strict latent state mediation, requiring predictions to depend only on the latent state and action,
is a classical principle that resolves this, but enforcing it in text-based settings is an open
challenge: textual latent states are discrete and non-differentiable, precluding variational
training, and expressive LLM decoders readily ignore the bottleneck. We show how to make strict
mediation work in the text domain. We formalize why it is necessary, showing that strict mediation
makes representation quality empirically testable while history-leaky architectures break this
connection. We then introduce textual latent states, which are discrete, interpretable, and
variable-length, and factorized GRPO (fGRPO), a tree-structured reinforcement learning method that
enforces strict mediation during training. Experiments on TextWorld and ScienceWorld show preserved
one-step prediction accuracy alongside up to 57% gains in representation quality and 98%
improvements in rollout performance, increasing with task complexity and horizon.

   



1 Introduction

World models learn the dynamics of an environment so that an agent can predict, plan, and reason
without further interaction (Sutton, 1991; Ha and Schmidhuber, 2018). In partially observed
settings, where observations reveal only fragments of the underlying state, a world model must
maintain a latent representation that summarizes the interaction history. This latent state is the
object on which rollouts operate, the branching point for counterfactual queries, and the
compressed summary that replaces an ever-growing history. A large body of work has focused on
building better dynamics models (Hafner et al., 2019a; Hafner et al., 2019b; Hafner et al., 2023;
Schrittwieser et al., 2020), but a dynamics model is only as good as the representation it operates
on. The central question is not only how to model dynamics, but how to know whether the learned
representation is adequate. This question is difficult to answer for an architectural reason. In
many existing world model architectures, the latent state coexists with other information that can
substitute for it. Sequence models condition on the full observation history and maintain no
explicit latent state (Yang et al., 2024; Li et al., 2025). Prompting-based approaches treat the
LLM context as an implicit state without learning a compressed representation (Hao and others, 2023
; Wang et al., 2024). Architectures that introduce a latent state but allow the decoder to also
access the history may ignore it entirely: the model can achieve strong predictive performance
while the representation carries no useful information (Xiang et al., 2025; Ge and others, 2024).
We call this the identifiability problem: when information can bypass the latent state, predictive
accuracy does not constrain representation quality. We propose strict latent state mediation to
address this: once a latent state is generated, all subsequent transitions and predictions depend
only on that state and the action. This mirrors the POMDP belief-state factorization (Kaelbling et
al., 1998; Murphy, 2000); classical world models with continuous latent states enforce it by
construction (Hafner et al., 2019a; Hafner et al., 2019b). However, recent LLM-based approaches
frequently relax this constraint through large contexts or hybrid conditioning, enabling
information to bypass the latent state. While this design improves predictive flexibility, it
breaks the connection between predictive performance and representation quality. A key consequence,
which motivates our approach, is that strict mediation makes representation quality empirically
testable. If a strictly mediated model predicts accurately, the latent state must contain all
task-relevant information; if it predicts poorly, the representation is insufficient. We formalize
this principle and derive three consequences that motivate our approach. Under strict mediation,
optimal predictive accuracy implies that the latent state is a sufficient statistic of history
(Proposition 1). Under leaky architectures, optimal accuracy is compatible with an uninformative
latent state (Proposition 2). Strict mediation also structurally aligns training and rollout
conditions, so that the model never conditions on information during training that is unavailable
during rollout, enabling bounded error propagation when dynamics are contractive, whereas
history-based and leaky rollouts suffer geometric error growth (Proposition 3). The central
technical challenge is enforcing strict mediation in text-based world models, where observations
and actions are natural language. Textual latent states align with the LLM backbone, enable
inspection, and provide an adaptive information bottleneck (Hafner et al., 2019a; Hafner et al.,
2019b; Hafner et al., 2025). However, they are discrete and non-differentiable, precluding
variational training, and expressive decoders make ELBO objectives prone to posterior collapse (
Bowman et al., 2016; He et al., 2019). We address this by treating latent state generation as a
stochastic policy and introduce factorized GRPO (fGRPO), a tree-structured extension that enforces
strict mediation during training. We evaluate on TextWorld (Côté et al., 2018) and ScienceWorld (
Wang et al., 2022). Our approach preserves one-step prediction accuracy (Proposition 1), yields
higher state-level F1 under matched prediction (Proposition 2), and improves rollout stability,
with gains growing from 5% at horizon 1 to 80% at horizon 9 (Proposition 3).

3 Why Strict Mediation Is Necessary

The architectural formulations in Section 2.2 differ only in what information is available at
prediction time, but this distinction has a fundamental consequence: whether predictive performance
constrains the learned representation.

3.3 Rollout Consistency and Stability

Strict mediation also affects multi-step rollout. The key distinction is whether the information
available at training matches rollout conditions.

Proposition 3 (Training–inference consistency).

In strictly mediated models, rollout and training operate on the same inputs (s^t,at)(\hat{s}_
{t},a_{t}), so one-step errors match. In leaky models, reliance on hth_{t} during training leads to
degraded rollout performance.

Beyond consistency, strict mediation changes how errors propagate. In stateless and leaky models,
errors accumulate through an expanding history, leading to worst-case geometric growth. In
contrast, strictly mediated models propagate error through a single latent state, enabling bounded
error under contraction assumptions. The bounded-error conclusion requires LS<1L_{S}<1, a property
of the learned dynamics, not the architecture; strict mediation ensures only the structural form of
the recurrence, not the contraction property itself. Table 4 summarizes these regimes; full
derivations are in Appendix B.

4 Enforcing Strict Mediation in the Text Domain

The preceding analysis establishes why strict mediation matters. We now address the central
challenge: enforcing it in the text domain, where latent states are discrete, non-differentiable,
and must be trained without variational objectives.

4.1 Textual Latent States

We represent latent states as text rather than continuous vectors. While classical world models use
continuous latents trained with variational objectives such as the ELBO (Hafner et al., 2019a;
Hafner et al., 2019b), this is best suited to low-dimensional settings. In text-based environments,
observations are free-form, horizons are long, and relevant information mixes entities, relations,
and attributes, making textual states a better match. Textual latent states offer four advantages.
(1) Alignment with LLMs: encoding, transition, and decoding are implemented as different
conditioning modes of a single model, avoiding lossy modality conversions. (2) Adaptive bottleneck:
capacity scales with content via variable-length representations, rather than a fixed-dimensional
constraint. (3) Interpretability: states are directly inspectable and can be evaluated against
ground-truth facts, enabling representation-centric evaluation. (4) Modality match: observations
are already semantic text, so textual states preserve their structure. The main tradeoff is that
textual states are discrete and non-differentiable, preventing standard reparameterization-based
training. In addition, expressive decoders trained with ELBO-style objectives can ignore the latent
state (posterior collapse) (Bowman et al., 2016; He et al., 2019). Under strict mediation, this
immediately harms prediction since there is no history bypass. Overcoming this training difficulty
is the core technical problem this paper addresses. We therefore train latent state generation
using reinforcement learning (Section 4.3).

State schema.

Strict mediation does not require a predefined latent-state vocabulary. In the most general form,
the latent state may be any textual object passed between encoding, transition, and decoding. In
this work, we instantiate latent states as JSON predicate–argument lists because they are easy to
parse, inspect, and compare. For the main experiments, we further restrict predicates to a
simulator-aligned vocabulary. This restriction is not required by the model, but enables more
comprehensive state-level evaluation (Section 5.3).

4.3 Training via Factorized GRPO

Section 4.2 defines the information flow; we now turn to the key algorithmic challenge: training
under strict mediation when the latent space is discrete text. Textual latent states are
non-differentiable, which precludes gradient-based optimization through the latent space. We treat
each generation stage (encoding, transition, and decoding) as a stochastic policy over text
sequences and optimize for predictive accuracy using reinforcement learning. Standard GRPO (Shao et
al., 2024) is incompatible with strict mediation: it operates on a single autoregressive
continuation of a fixed prompt, so the transition and decoding steps would access the original
history through the shared prompt context. We introduce factorized GRPO (fGRPO, Figure 1), which
extends GRPO to tree-structured, multi-prompt rollouts. For a given history hth_{t}, we sample AA
candidate latent states, then BB candidate next states per encoding, then CC candidate observations
per transition, forming a tree with hth_{t} as root and o^t+1(a,b,c)\hat{o}_{t+1}^{(a,b,c)} as
leaves. From a single tuple (ht,at,ot+1)(h_{t},a_{t},o_{t+1}), this yields 1+A+A​B1+A+AB GRPO
groups (Figure 1d). Rewards are computed at the leaves by comparing o^t+1(a,b,c)\hat{o}_{t+1}^
{(a,b,c)} with ot+1o_{t+1} and propagated upward by averaging over children so each parent takes
the mean reward of its immediate descendants; advantages are computed group-relative within each
level. All groups are aggregated into a single batch to update the shared LLM parameters.

5 Experimental Evaluation

Our evaluation targets representation quality, rather than downstream control or planning
performance. Under strict mediation, representation properties become empirically identifiable: if
a latent state is sufficient, compact, and stable, these properties should manifest directly in
prediction behavior.

5.1 Datasets

Our evaluation requires environments that are partially observed for the agent but fully
instrumentable for the developer: the model sees only textual observations, while we access the
complete Markov state for evaluation. We use two text-based benchmarks: TextWorld (Côté et al.,
2018) and ScienceWorld (Wang et al., 2022). Both define a fully specified symbolic state but render
only a lossy natural-language observation at each step; a single observation is generally
insufficient to identify the underlying state. We generate offline datasets by executing a diverse
set of behavior policies (expert, ϵ\epsilon-greedy, exploration-then-oracle, random walk, and
failure modes) and logging trajectories of observations and actions. For TextWorld, we generate
2,7262,726 trajectories (121,054121,054 steps) across 261261 game configurations varying in world
size (11–1212 rooms), recipe length (11–55 ingredients), and skill requirements, with 2424 random
seeds per configuration. For ScienceWorld, we generate 600600 trajectories (19,48119,481 steps)
across 3030 task types. Average trajectory length is 4545 steps for TextWorld and 3333 for 
ScienceWorld. The main training set contains 2,2872,287 trajectories (102,920102,920 steps) for TW
and 540540 trajectories (17,57317,573 steps) for SW, with permanent holdout sets of 439439 TW
trajectories and 6060 SW trajectories reserved for final evaluation. All model training is strictly
offline, without further environment interaction. Full details on data generation, complexity
sweeps, noise injection, ground-truth logging, and holdout design are provided in Appendix D.

5.2 Baselines

We compare against three baselines corresponding to the architectural formulations in Section 2.2,

can rely on the history bypass as discussed in Proposition 2. StrictState-Emb follows the strict
formulation but replaces textual latent states with continuous embeddings, as a fixed number of

5.3 Evaluation Metrics

Our evaluation targets representation quality rather than downstream control, using three metrics. 
Observation-level F1 (obs.F1) measures next-observation prediction quality: we extract structured
facts (predicates and arguments) from both the predicted and ground-truth observations and compute
F1 over the extracted fact sets (Appendix F.1), directly measuring whether the model predicts the
correct environment facts rather than matching surface text. State-level F1 (state.F1) evaluates
latent states by parsing them into structured predicates and computing F1 against the subset of
ground-truth facts needed to render the next observation^1^1 1 Ground-truth states are hidden from
the model and used only for final evaluation.. This rendering-derived subset provides an exact
sufficiency target without requiring irrelevant simulator variables (Appendix D). We additionally
report the compression ratio (CR), defined as the ratio between the cumulative history length and
the latent state length, measuring how aggressively the model compresses history into its
representation. Finally, to evaluate temporal consistency, we measure state.F1 across multi-step
rollouts at increasing prediction horizons HH; degradation as HH increases reflects the
accumulation of prediction errors and allows comparison of rollout stability across models. We use
greedy decoding during evaluation and report ±1\pm 1 standard error over test examples as error

Rollout stability.

Table 2 reports performance across increasing prediction horizons HH. StrictState-Text consistently
outperforms LeakyState, with gains growing from +5% at H=1H{=}1 to +98% at H=9H{=}9 on TextWorld
(4B model). This supports Proposition 3: leaky models suffer from training-inference mismatch,
relying on history during training that is unavailable during rollout, while strict models operate
under identical conditions in both regimes. Consistent with the error propagation analysis in
Appendix B, the gap widens with horizon, confirming that strict mediation mitigates cumulative
error propagation. The long-horizon gains further suggest that the compactness rewards (e.g.,
RablR_{\text{abl}}) do not simply collapse the textual state to immediately visible facts;
future-relevant facts can still be retained when they support the learned rollout dynamics.

Reward ablation.

Table 3 evaluates the contribution of each reward component. At horizon H=1H{=}1, obs.F1 is
comparable across configurations, but differences emerge at longer horizons, revealing that the
auxiliary rewards improve the state’s capacity to support multi-step rollout. Observation accuracy
alone (RobsR_{\text{obs}}) produces largely invalid latent states; adding format validity (RfmtR_{\
text{fmt}}) enforces structure but reduces obs.F1, as the model must now route prediction through a
structured bottleneck. The support reward (RsupR_{\text{sup}}) is critical: it recovers
short-horizon obs.F1 and produces the largest long-horizon gains (H=9H{=}9: 0.345→0.5410.345\
rightarrow 0.541), indicating that aligning the latent state with predicted observations directly
improves rollout stability. Deduplication (RdedR_{\text{ded}}) and ablation (RablR_{\text{abl}})
further increase compactness (CR: 24.3→58.224.3\rightarrow 58.2) while maintaining long-horizon
performance, yielding states that are both minimal and predictively sufficient over extended
rollouts.

Latent world models. Classical world models such as RSSM (Hafner et al., 2019b), Dreamer Hafner et
al. (2019a); Hafner et al. (2020); Hafner et al. (2025), and MuZero (Schrittwieser et al., 2020)
learn continuous latent states with explicit transition models, enforcing a Markov factorization in
which predictions depend only on the current state and action. Our work shares this commitment to
strict mediation but operates in the text domain, where latent states are discrete and variational
training is poorly matched (Section 4.1). More recent approaches relax this factorization:
DreamerV4 (Hafner et al., 2025) conditions on the full sequence of past latent embeddings, and PAN
(Xiang et al., 2025) uses an autoregressive LLM backbone over the entire latent history. Our
analysis in Section 3.2 formalizes the consequence: when the architecture permits history bypass,
predictive accuracy does not constrain the representation. LLMs as world models. RAP (Hao and
others, 2023) formulates reasoning as planning over textual states using a frozen LLM, enforcing
strict mediation by construction but operating in fully observed MDPs without learning. Wang et al.
(2024) evaluate LLMs on single-step state prediction given the full ground-truth state. Li et al.
(2025) fine-tune LLMs on offline trajectories but condition on the full observation history without
learning a compressed latent state. In all cases, either partial observability is absent, or no
explicit latent representation is learned, or both. Our work addresses both. Since even a
fine-tuned history-conditioned model fails to produce identifiable representations, the limitation
is structural rather than a matter of model capacity or prompting strategy. Representation learning
for sequential decision-making. The information bottleneck principle (Tishby et al., 2000) provides
the theoretical foundation for compressed representations that retain task-relevant information.
JEPA-style methods (LeCun and others, 2022) learn representations via embedded prediction rather
than reconstruction. Our approach retains this signal but replaces variational training with
reinforcement learning and enforces strict mediation to ensure identifiable sufficiency. Detailed
comparison with prior work is in Table 5 in appendix.

7 Conclusion

We have shown that strict latent state mediation can be effectively enforced in text-based world
models through factorized GRPO, yielding identifiable, interpretable representations whose quality
is directly diagnosable from predictive performance. Confirmed empirically across compositional
difficulty levels and prediction horizons, the resulting textual latent states compose entities,
relations, and attributes as variable-length text, opening the door to LLM-grounded reward signals
in settings where precise reward models are unavailable. The natural next steps are extending
strict mediation to recurrent or hierarchical encoders that process history incrementally, and
demonstrating that the representation-level gains established here translate into improved planning
and task completion. Limitations. Our evaluation focuses on representation quality rather than
downstream control or planning, and is limited to two synthetic, instrumented environments
(TextWorld and ScienceWorld), which may not fully reflect real-world complexity. Two structural
limitations also merit discussion. First, strict mediation places the full burden of history
compression on a single-shot encoder with no incremental refinement, so any missed information is
irrecoverable, since removing history bypass also removes the decoder’s ability to compensate for
encoder errors. Second, while strict mediation and fGRPO are environment-agnostic, the auxiliary
rewards that shape representations into interpretable, compact forms rely on structured fact
extraction; extending these to less structured domains will require alternatives like learned
similarity metrics or LLM-based evaluation. Broader Impacts. This work is primarily methodological
and may improve the reliability and interpretability of AI systems. Potential risks include misuse
of more capable generative models, though our study is limited to offline benchmarks and does not
involve deployment.

A.3 Full Proof of Proposition 3

Proof.

Under strict mediation, the model’s prediction at each step depends only on (s^t,at)(\hat{s}_{t},a_
{t}). During training, the model receives (s^t,at)(\hat{s}_{t},a_{t}) and produces pθ​(ot+1∣s^t,at)
p_{\theta}(o_{t+1}\mid\hat{s}_{t},a_{t}). During one-step rollout, the model receives the same
input types and produces the same function. The information available to the model is identical in
both regimes, so the one-step prediction error is the same. In multi-step rollout, the latent state
s^t+k\hat{s}_{t+k} is generated recursively by the learned transition function rather than encoded
from the true history. The marginal distribution over latent states therefore shifts relative to
training (covariate shift). However, under strict mediation, this shift is governed entirely by the
transition function’s error propagation, formalized in Appendix B via the contraction analysis:
when LS<1L_{S}<1, the state error remains bounded. Crucially, the form of the input does not change
between training and rollout; the model always conditions on (s^t,at)(\hat{s}_{t},a_{t}) and never
on hth_{t}. Therefore there is no structural mismatch of the kind that affects leaky architectures.
Under a leaky architecture, the model’s training-time prediction is pθ​(ot+1∣s^t,ht,at)p_{\theta}
(o_{t+1}\mid\hat{s}_{t},h_{t},a_{t}), which may depend on hth_{t}. During rollout, the true history
is unavailable and must be replaced by the synthetic history of past predictions (o^t+1,…,o^t+k)(\
hat{o}_{t+1},\ldots,\hat{o}_{t+k}). This introduces both covariate shift (the synthetic history has
different statistics than the true history) and a structural input mismatch (the model was trained
with access to true history but must operate without it). Any learned dependence on hth_{t} leads
to degraded rollout performance that cannot be bounded by transition error alone. ∎

Remark on discrete latent states.

The error propagation analysis above uses norm-based distances and Lipschitz continuity, which are
defined for continuous spaces. When latent states are discrete text strings, as in our
instantiation, the appropriate distance metric is a discrete divergence such as edit distance,
fact-level F1 complement (1−F11-\text{F1}), or token-level Hamming distance. The structural form of
the recurrence which is error propagating through a single state rather than an expanding history,
holds under any distance metric satisfying the triangle inequality. The contraction condition LS
<1L_{S}<1 generalizes to requiring that the transition function is a contraction mapping under the
chosen metric. Our experimental evaluation uses fact-level F1, which serves as the discrete
analogue of the norm-based analysis: the bounded rollout error predicted by the theory manifests as
slower state.F1 degradation over horizon for StrictState compared to LeakyState (Table 2). (3)

Appendix D Dataset Details

Environments and partial observability.

Both environments define a fully specified symbolic state (entities, attributes, relations, and
task variables), but render only a lossy natural-language observation at each step. Observations
may omit relevant variables, compress multiple state features into a single description, or vary in
surface form without changing semantics. As a result, a single observation is generally
insufficient to identify the underlying state, and accurate prediction requires integrating
information across time.

Controlling challenge factors.

To comprehensively probe robustness and abstraction, we vary multiple factors during generation. In
TextWorld, we sweep game complexity through world size (number of rooms), task complexity (e.g.,
recipe length), and skill requirements (e.g., navigation vs. cooking/cutting/opening), and generate
multiple instances via random seeds (yielding different layouts and object placements). In both 
TextWorld and ScienceWorld, we additionally inject controlled nuisance variation and noise into
actions and/or text (e.g., exploration noise, invalid attempts, lexical perturbations), with step-
and trajectory-level metadata recording action provenance and noise type. These knobs let us
separately stress partial observability, long-horizon credit assignment, and sensitivity to
semantically irrelevant perturbations.

Ground-truth state logging.

While the model never observes the ground-truth state, we log it for evaluation and diagnostics. At
each timestep, we extract the full symbolic simulator state as a set of structured
predicate–argument facts (e.g., at(entity, room), in(object, container), on(object, supporter),
object attributes such as open, closed, or food states such as raw, cooked). These facts are
obtained directly from the game engine’s internal state representation via instrumentation, using
the same underlying rules that govern environment dynamics, and are not inferred from observations
or constructed manually. From this full post-action state, we construct a canonical subset of
observation rendering facts, defined as the minimal set of facts required by the environment’s
rendering logic to produce the natural-language observation. This subset is computed
deterministically by following the game engine’s observation-generation rules (e.g., Inform7/
TextWorld rendering), rather than by heuristic or learned extraction. Concretely, it includes (i)
the player’s current location, (ii) all objects present in the current room, (iii) attributes of
visible objects (such as food states or container states), (iv) contents of containers when they
are open, (v) objects placed on supporters, and (vi) spatial relations and connectivity facts
(e.g., exits, doors, and directions) needed to describe the layout. For actions such as look or
navigation, this corresponds to the full set of facts required to render the room description; for
local actions (e.g., take, open, examine), it includes only the subset of post-action facts
explicitly reflected in the resulting observation. Because both the full state and the observation
rendering facts are derived directly from the game engine using its native rules, this construction
provides an exact and unambiguous symbolic target aligned with the generated observation text. It
therefore enables precise evaluation of predictive sufficiency: state.F1 measures whether the
learned latent state captures exactly the information required to reproduce the next observation,
independent of surface-form variation. In addition, access to the full logged state enables
auxiliary diagnostics, such as verifying transition consistency across equivalent histories and
distinguishing true state uncertainty from errors due to textual variation.

Appendix F Experiment Details

F.1 Fact Extraction from Observations

All observation-level rewards and metrics operate on structured fact sets extracted from free-form
observation text. Given an observation oo, we define a deterministic mapping facts⁡(o)\mathrm
{facts}(o) that produces a set of predicate instances (e.g., in(apple, fridge), open(fridge)). The
extractor operates purely on surface text and does not access hidden simulator states. For each
environment, we use a rule-based parser aligned with the observation templates to recover entities,
relations, and attributes explicitly stated or strongly implied by the text (e.g., location,
containment, object state, and action effects). We additionally apply a small set of deterministic
rules (e.g., fried(X) ⇒\Rightarrow cooked(X)) to capture logical implications. While our
implementation uses environment-specific parsers, the framework does not depend on simulator
internals. In domains without structured templates, facts⁡(⋅)\mathrm{facts}(\cdot) can be
instantiated using alternative text-to-structure extractors, such as rule-based systems or frozen
LLMs.

F.2 Rewards

Fact extraction and observation reward.

All fact-level rewards used in this work are computed from text, not from privileged simulator
latent states. Let facts⁡(⋅)\mathrm{facts}(\cdot) denote a fact extractor applied either to a
free-form observation string or to a generated textual state. For observations, facts⁡(o)\mathrm
{facts}(o) extracts a set of structured facts from the observation text; for latent states, facts⁡
(s)\mathrm{facts}(s) parses the JSON-encoded facts generated by the model. The observation reward
compares the predicted observation text o^t+1\hat{o}_{t+1} with the reference next observation text
ot+1o_{t+1}:

 Robs=F1⁡(facts⁡(o^t+1),facts⁡(ot+1)).R_{\text{obs}}=\operatorname{F1}\bigl(\mathrm{facts}(\hat{o}
 _{t+1}),\mathrm{facts}(o_{t+1})\bigr).

In our experiments, the observation fact extractor is simulator-aligned in the sense that it
follows the observation templates and predicate schema of the benchmark environments. However, it
is applied only to surface-level observation strings and generated state strings; it does not query
hidden simulator states or privileged environment variables. In environments where such a
simulator-aligned extractor is unavailable, the same framework can use any domain-specific
text-to-facts extractor, for example a rule-based parser or a frozen LLM extractor calibrated with
few-shot labeled observation examples.

State format reward.

We enforce a lightweight structural constraint on the generated latent state. The state must be a
JSON-encoded list of facts, where each fact is a dictionary with exactly two keys, "predicate" and 
"arguments". The predicate must be a non-empty string, and the arguments must be a list of
non-empty strings. No argument may exceed max_num_words_in_arg words (set to 8 for ScienceWorld and
3 for TextWorld cooking). Duplicate facts are disallowed, and duplicate arguments within a single
fact are not permitted. The format reward Rfmt∈{0,1}R_{\text{fmt}}\in\{0,1\} indicates whether
these constraints are satisfied.

Auxiliary state rewards.

For valid latent states (Rfmt=1R_{\text{fmt}}=1), we compute additional rewards to encourage
semantic correctness and compactness. These rewards also operate only on extracted facts from text.
Support reward. The support reward RsupR_{\text{sup}} measures whether facts stated in the
predicted next observation o^t+1\hat{o}_{t+1} are represented in the predicted next latent state s^
t+1\hat{s}_{t+1}. We parse both the generated state text and the predicted observation text into
fact sets and compute fact-level observation coverage:

 Cov⁡(s^,o^)=|facts​(s^)∩facts​(o^)||facts​(o^)|.\operatorname{Cov}(\hat{s},\hat{o})=\frac{|\text
 {facts}(\hat{s})\cap\text{facts}(\hat{o})|}{|\text{facts}(\hat{o})|}.

We define

 Rsup=Cov⁡(s^t+1,o^t+1)+(Cov⁡(s^t+1,o^t+1)−Cov⁡(s^t,o^t+1)),R_{\text{sup}}=\operatorname{Cov}(\hat
 {s}_{t+1},\hat{o}_{t+1})+\bigl(\operatorname{Cov}(\hat{s}_{t+1},\hat{o}_{t+1})-\operatorname{Cov}
 (\hat{s}_{t},\hat{o}_{t+1})\bigr),

which rewards the predicted next latent state for containing the facts needed to support the
predicted next observation, as well as improvement over the current latent state. Importantly,
RsupR_{\text{sup}} does not penalize s^t+1\hat{s}_{t+1} for containing additional latent facts that
are not expressed in the immediate observation, thereby allowing the retention of long-term
information. Deduplication reward. The deduplication reward RdedupR_{\text{dedup}} penalizes
redundant or contradictory facts. Each fact is converted into a short natural-language sentence,
and all unordered pairs are evaluated using an NLI model^3^3 3 https://huggingface.co/sileod/
deberta-v3-base-tasksource-nli. A pair is considered redundant if either the entailment or
contradiction score exceeds 0.5. Let NdupN_{\text{dup}} be the number of such pairs and NpairsN_{\
text{pairs}} the total number of pairs. The reward is

 Rdedup=1−NdupNpairs,R_{\text{dedup}}=1-\frac{N_{\text{dup}}}{N_{\text{pairs}}},

computed for both sts_{t} and st+1s_{t+1} and averaged.

Ablation reward.

The ablation reward RablR_{\text{abl}} measures whether individual facts in s^t+1\hat{s}_{t+1} are
necessary for prediction. For each fact, we remove it from the state, decode an observation from
the ablated state, and compare it to the observation decoded from the full state. A fact is marked
as necessary if its removal reduces the decoded observation fact-level F1 by more than 0.05. The
reward is the fraction of necessary facts:

 Rabl=NnecessaryNfacts.R_{\text{abl}}=\frac{N_{\text{necessary}}}{N_{\text{facts}}}.

This reward is not intended to define sufficiency of the latent state by itself: because the
leave-one-out test is local to the sampled transition, a fact may be useful for future or
counterfactual actions even if its removal does not affect the decoded observation for the current
action. We therefore apply RablR_{\text{abl}} only at a late stage of training and with a small
coefficient, treating it as a weak compactness regularizer. Predictive sufficiency is enforced
primarily by strict mediation and the observation reward over diverse action-conditioned
transitions. In practice, RablR_{\text{abl}} biases the model against stale or redundant facts
without aggressively pruning persistent state information needed for long-horizon rollout. All
leave-one-out decoder evaluations are performed in parallel.

Invalid states.

If a latent state fails the format constraint (Rfmt=0R_{\text{fmt}}=0), auxiliary rewards are not
applied. Instead, the total reward is given by the penalized observation reward Robs⋅γpenR_{\text
{obs}}\cdot\gamma_{\text{pen}}.

F.3 Models and Training Setup

We experiment with three pretrained instruction-tuned language models: Qwen2.5-0.5B-Instruct (0.5B
parameters), Qwen3-4B-Instruct-2507 (4B parameters) and Qwen3-32B (32B parameters). These models
serve as the shared backbone for encoding, transition, and decoding, with all stages implemented
via prompting as described in Section 4. Training is performed using factorized GRPO with
tree-structured rollouts. Unless otherwise specified, we use a branching factor of A=B=C=4A=B=C=4,
i.e., each node expands to 4 candidates at each stage (encoding, transition, and decoding). We
train for a single epoch over the offline dataset with learning rate 1×10−61\times 10^{-6}. The
reward weighting coefficients are set to γpen=0.5\gamma_{\text{pen}}=0.5 and λdedup=λabl=λsup=0.1\
lambda_{\text{dedup}}=\lambda_{\text{abl}}=\lambda_{\text{sup}}=0.1.

F.5 Parallelized factorized GRPO.

We implement fGRPO using an asynchronous tree-rollout engine integrated with verl and vLLM. For
each training example, the encoder, transition, and decoder stages are expanded as separate prompt
calls, but sibling generations from the same parent node are submitted concurrently. Concretely,
all AA encoder samples, all BB transition samples under each encoded state, and all CC decoder
samples under each predicted next state are launched asynchronously, allowing the rollout tree to
be generated in parallel rather than by a serial depth-first traversal. The resulting tree is then
flattened into GRPO training samples, with the grouping identifier set to the parent node of each
sibling set so that group-relative advantages are computed separately for encoder, transition, and
decoder decisions. This design avoids relying on the standard verl mechanism that repeats prompts
before generation. Instead, rollout multiplicity is controlled inside the world-model rollout
itself, which is necessary because different nodes in the tree have different prompts and
conditioning contexts. We also share request identifiers among siblings generated from the same
parent prompt, enabling the rollout backend to batch compatible requests efficiently. For the
ablation reward, decoder calls for the full state and all leave-one-fact-out states are likewise
submitted concurrently; we skip this computation when it would be identical across decoder-only
siblings and therefore cancel out in the GRPO advantage.
